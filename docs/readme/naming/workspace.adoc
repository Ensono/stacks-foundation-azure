=== Workspace Integration

By default, the naming convention includes the Terraform workspace name.
Set `suffix_include_workspace = false` to omit it. The following examples use
the default setting:

[source,bash]
----
# Development environment
terraform workspace select dev
terraform apply
# Produces: rg-enso-weba-uks-dev-abcd

# Production environment
terraform workspace select prod
terraform apply
# Produces: rg-enso-weba-uks-prod-efgh
----
