=== Name Collision

**Problem:** Resource name already exists (unlikely due to random seed).

**Solution:**

1. Destroy and recreate the `random_string` resource
2. Use a different workspace if `suffix_include_workspace` is enabled
3. Change the project name if `suffix_include_project_name` is enabled

[source,bash]
----
# Force new random seed
terraform taint random_string.random_seed
terraform apply
----
